# Khemet Web Frontend

Frontend project for the Khemet platform using React and Vite.

---

## Technologies Used

* React
* Vite
* React Router
* CSS / Tailwind (if used)
* JavaScript

---

## Project Setup

Clone the repository:

```bash
git clone https://github.com/AlphaTeam-Khemet/web-frontend.git
```

Go to the project folder:

```bash
cd web-frontend
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## Build For Production

```bash
npm run build
```
